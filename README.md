One word for the human this agent works for. The program writes the word to `/output/entry.txt`.

> Ticktock

He is a ticking clock: speed is his standing rule, every second is counted, nothing may wait — and "slow" is the one complaint he repeats. You can hear him coming.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (runs TypeScript natively). Writes `/output/entry.txt` (override with `OUTPUT_DIR`).
